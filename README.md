# lib-respect

A TUI that visualizes the dependency libraries of your repositories and allows you to visit their authors' GitHub profiles with respect. Written in Rust.

## Challenges and Solutions Provided by This App

- The Rust ecosystem is amazing! I always find myself using someone's libraries. I want to show my respect by starring them!
- Wait, did I star this library...? Oh, I missed it. I want to visualize the libraries I haven't starred yet and visit their authors' GitHub profiles with respect!
- So, that's why I created this. While it primarily focuses on Rust, it also supports some parts of CMake.
