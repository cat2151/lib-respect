# lib-respect

A TUI that visualizes your repository's dependency libraries and allows you to respectfully visit their authors' GitHub profiles. Written in Rust.

## The Problem and This App's Solution
- The Rust ecosystem is amazing! I'm always relying on someone's libraries. I want to give them a star out of respect!
- Wait, did I star this library...? Oh, I missed it! I want to visualize libraries I've forgotten to star and then respectfully visit the author's GitHub profile!
- That's why I built this. While primarily focused on Rust, it also supports some CMake projects.

## Installation

Rust is required.

```sh
cargo install --force --git https://github.com/cat2151/lib-respect
```

## Usage

```sh
lib-respect
```

## Updating

```sh
lib-respect update
